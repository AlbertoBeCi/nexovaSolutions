# 📚 Aprendiendo Nexova

Guías cortas, en español sencillo, con ejemplos y un tema por archivo.

## 🧭 Elige el tema

| Guía | Qué aprenderás |
| --- | --- |
| [📊 pandas](aprendiendoPandas.md) | Leer CSV, validar tickets y calcular métricas. |
| [🌐 FastAPI](aprendiendoFastAPI.md) | Entender rutas, peticiones, respuestas y dependencias. |
| [✅ Pydantic](aprendiendoPydantic.md) | Validar datos y separar entrada de salida. |
| [🗃️ TinyDB](aprendiendoTinyDB.md) | Guardar registros, usar IDs y cargar datos iniciales. |
| [🖥️ React](aprendiendoReact.md) | Conectar la pantalla de incidencias con la API. |
| [🏢 Proveedores](aprendiendoProveedores.md) | Entender el CRUD, los filtros y la app de operaciones. |
| [🛠️ uv y entorno](aprendiendoUV.md) | Instalar dependencias y arrancar cada aplicación. |
| [🧪 pytest](aprendiendoPytest.md) | Comprender las pruebas y sus resultados. |
| [🧰 ORM e inventario](aprendiendoORM.md) | Entender SQLModel, Supabase y el stock del Hito 5. |
| [📦 Interfaz de inventario](aprendiendoBackofficeInventario.md) | Entender las vistas, la autenticación, el stock y los errores del backoffice. |
| [⚡ Rendimiento y caché](aprendiendoCachingRendimiento.md) | Entender la carga diferida, `useMemo`, el TTL y la invalidación de caché. |
| [🐳 Docker Compose](aprendiendoDocker.md) | Arrancar el entorno local, entender los contenedores, la red y los volúmenes. |

## 🚀 Por dónde empezar

Para ponerlo en marcha, comienza por **uv y entorno**. Para entender el recorrido de los datos, sigue **pandas → FastAPI → React**.

Las guías enlazan al código para ampliar cada concepto. Se guardan en la raíz y están ignoradas por Git, igual que el índice original.
