# Project brief

Proyecto transversal de **4Geeks Academy — AI Engineering** sobre la empresa
ficticia **Nexova Solutions** (consultora de RRHH y adquisición de talento,
Valencia + Miami). Se construye "una empresa" a lo largo de varios hitos.

Fuente de verdad del dominio: [`CONTEXT.md`](../CONTEXT.md).

## Hitos

| Hito | Entregable | Estado |
| --- | --- | --- |
| 1 — Web pública | Landing corporativa + formulario de captación de talento, responsive, accesible, SEO, Tailwind | Entregado como HTML estático en la raíz (`index.html`, `application.html`) |
| 3 — Talent Pipeline | App interna: listado de candidaturas con filtros, ficha de candidato, alta/edición, notas internas; consume la API de 4Geek Tracker | En curso (`uis/backoffice/`) |

Además existe una capa de **modelo de dominio en TypeScript** (`packages/domain/`,
Hito 2) con
candidatos, vacantes, procesos de selección y utilidades de scoring/filtrado.

## Alcance de idioma

Idioma base del producto: **español**. Un segundo idioma sería mejora, sin bajar
la calidad del español.
